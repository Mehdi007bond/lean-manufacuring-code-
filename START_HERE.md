## 📋 Quick Instructions

### Option 1: Use Overleaf (RECOMMENDED)

1. **Open** the file `document.tex` in this repository
2. **Copy** everything (Ctrl+A, then Ctrl+C)
3. **Go to** [overleaf.com](https://overleaf.com) and create a new blank project
4. **Delete** everything in the default `main.tex` file
5. **Paste** your code (Ctrl+V)
6. **Click** "Recompile"
7. **Done!** Your beautiful document will appear on the right side
